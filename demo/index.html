<pattern-grid>

A vanilla web component that stamps out a CSS-Grid of empty cells and gets out of the way.

1. Hero — animated doodle

2. Hello rainbow

<pattern-grid cells="8x8"></pattern-grid>

3. Concentric rotation

<pattern-grid cells="32"></pattern-grid>

4. 2D coordinates from sibling-index

<pattern-grid cells="16x16"></pattern-grid>

5. Template cells

<pattern-grid cells="4x4">
  <template><button class="tile">+</button></template>
</pattern-grid>

6. Hand-authored cells (no JS required)

Open with NoScript or block JS — the cells still render because they are real HTML.

<pattern-grid cols="3" rows="2">
  <a href="/one"></a><a href="/two"></a><a href="/three"></a>
  <a href="/four"></a><a href="/five"></a><a href="/six"></a>
</pattern-grid>

7. Vanilla Breeze tokens

/* VB tokens cascade into light DOM children */
pattern-grid > i {
  background: hsl(... var(--vb-color-saturation) var(--vb-color-lightness));
  border-radius: var(--vb-radius-sm);
}

8. Sibling shim — works in Firefox

With shim="sibling" (works everywhere):

Without shim (requires native sibling-index()):

<pattern-grid cells="36" shim="sibling"></pattern-grid>

pattern-grid > i {
  --idx: var(--i, sibling-index()); /* shim first, native fallback */
  background: hsl(calc(var(--idx) * 10) 70% 50%);
}
